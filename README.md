# Winter Arc

Фитнес-приложение с темой Winter Arc: тренировки, прогресс, награды, мотивация и система заработка.

## Что внутри
- Frontend: React + Vite + TypeScript
- Backend: Node.js + Express
- Backend API для авторизации и прогресса
- Современный дизайн в холодной цветовой палитре

## Структура
- `frontend/` — интерфейс приложения
- `backend/` — API сервер

## Запуск

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Запустите проект:
   ```bash
   npm run dev
   ```

3. Откройте в браузере:
   - Frontend: http://localhost:5173
   - Backend: http://localhost:5000

## Основные функции
- dashboard с прогрессом
- тренировки и планы
- система streak
- достижения (Winter Arc)
- рейтинг и с��циальная мотивация
- базовая регистрация и вход
